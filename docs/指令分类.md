# PowerShell 指令分类

三个核心模块的指令按实现方式归类：
分类说明：
- **内置**：用 Go 原生实现（保持对象管道语义）。
- **映射 Linux**：委托给对应的 Linux 命令/工具。
- **跳过**：Windows 专属 / 远程会话 / GUI / 模块管理 / 调试等，平台无关或超范围。

> 实现状态：三个核心模块共约 245 个指令，本程序内置实现 114 个；未实现且能直通的
> 命令（如 mkdir、ping、curl 等）会作为外部命令在 PATH 中执行。标记"跳过"的为
> 平台无关或超范围项。见 git 历史各批次提交。
>
> 详细文档：
> - [指令参考.md](指令参考.md) —— 面向用户：每条指令的映射、版本、发行版与两个例子。
> - [指令详解.md](指令详解.md) —— 开发文档：每条指令逐参数、逐字段的完整说明。
> - [未实现指令.md](未实现指令.md) —— 全部未实现指令清单及原因。

## 5.X 与 7.X 的实际差异

- `$PSVersionTable`：5.X → PSVersion=5.1、PSEdition=Desktop；7.X → PSVersion=7、PSEdition=Core、GitCommitId、OS、Platform。
- 自动变量：7.X 有 `$IsLinux/$IsWindows/$IsMacOS`；5.X 无（引用得 $null）。
- 默认别名集差异（见上）。
- 语法与命令不按风格限制：`??` 空合并、三元 `?:`、`-f` 格式、`$i++` 增量、`-in`/`-contains` 等 7.X 语法，以及 Test-Json、Join-String、Get-Uptime 等 7 新增命令，本程序在 5.X 风格下同样可用。

## 交互外壳行为

- 输入 `powershell` 进入命令行进程，工作目录为 Linux 根目录 `/`。
- 提示符固定为 Windows 风格：`PS C:\>`（`C:\` 对应 `/`）。
- 输入的命令直接映射为 Linux 命令执行；需要提权的用 sudo 以 PowerShell 方式执行。
- 默认命令格式为 PowerShell 7；运行 `Set-PSVersion 5.1`（别名 `switchstyle`）切到 5。
