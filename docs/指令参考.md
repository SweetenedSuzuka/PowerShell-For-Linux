# PowerShell 指令参考

这份文档面向使用者，列出本程序支持的指令。指令分两类：

- **Go 实现** —— 行为在本程序内部用 Go 复现，不调用外部命令。多数与 Windows PowerShell 行为一致，有差异的会写明。
- **映射 Linux 命令** —— 直接调用系统里的原生命令（`systemctl`、`ping`、`xclip` 等）。

每条指令给两个例子：一个基础、一个稍复杂，并说明例子做了什么。原版官方说明见《[指令详解-原版跨平台指令](指令详解-原版跨平台指令.md)》与《[指令详解-原版Windows指令](指令详解-原版Windows指令.md)》对应小节（每条都有链接）。

通用的几点：

- 目录显示成 Windows 风格（根目录显示成 `C:\`），但操作 Linux 文件系统。
- `C:` 表示系统盘，其实就是根目录：`cd C:\tmp` 等同 `cd /tmp`，`C:` 或 `C:\` 就是根。其它盘符（`D:`、`E:` 等）在 Linux 上不存在，输入会报错。
- 默认用 PowerShell 7 的命令格式；想切到 5 的格式用 `Set-PSVersion 5.1`。风格只影响横幅、`$PSVersionTable`、别名与自动变量：5 风格里 `curl`、`wget`、`sc` 三个别名可用，7 没有；5 的 `$PSVersionTable` 显示 PSVersion=5.1、PSEdition=Desktop，7 显示 PSVersion=7、PSEdition=Core、GitCommitId、OS、Platform，`$IsLinux` 这类变量只在 7 里存在。
- "版本"标的是命令在原版 PowerShell 里的归属：写"5.1 和 7"表示 5.1 与 7 都有，写"7"表示 7 才有。本程序不按风格限制命令，两种风格下都能调用（如 Test-Json、Join-String、Get-Uptime 在 5 风格下同样可用）。
- "发行版：所有"表示任何发行版都能用；写了具体依赖（systemd、X11、ping 等）的就只有满足条件的环境能用。

## 进入和切换

### 启动
直接运行 `powershell` 进入命令行，默认在 Linux 根目录，提示符 `PS C:\>`，默认用 7 的命令格式。

### Set-PSVersion（switchstyle）
- 类型：Go 实现（本程序扩展）。
- 版本：本程序扩展。发行版：所有。
- 功能：切换 5.X / 7.X 命令格式，横幅、`$PSVersionTable`、别名、自动变量随之变化。
例：
- `Set-PSVersion 5.1` —— 切到 5 的格式。
- `Set-PSVersion 7; $PSVersionTable.PSEdition` —— 切回 7，并显示格式名（显示 Core）。


### Get-Host
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：返回主机对象。InstanceId 为本会话随机 UUID，区域按界面语言返回（未登记的语言用 zh-CN）。
例：
- `Get-Host` —— 显示主机对象。
- `Get-Host | Select-Object Name,InstanceId` —— 只看名称和会话标识。

原版官方说明：[Get-Host](指令详解-原版跨平台指令.md#get-host)。

## 目录导航

### Get-Location（pwd、gl）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：显示当前目录，对应 bash 的 `pwd`。
- 与 Windows PowerShell 的差异：直接输出路径字符串（PowerShell 显示成 PathInfo 对象的 Path 表格）。
例：
- `pwd` —— 显示当前目录（相当于 bash 的 `pwd`）。
- `Set-Location /tmp; Get-Location` —— 先切到 /tmp 再显示（相当于 bash 的 `cd /tmp; pwd`）。

原版官方说明：[Get-Location](指令详解-原版跨平台指令.md#get-location)。

### Set-Location（cd、sl、chdir）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：切换目录，对应 bash 的 `cd`。
- 与 Windows PowerShell：行为一致。
例：
- `cd /etc` —— 切到 /etc（相当于 bash 的 `cd /etc`）。
- `Set-Location $HOME; Get-Location` —— 切回家目录再确认（相当于 bash 的 `cd ~; pwd`）。

原版官方说明：[Set-Location](指令详解-原版跨平台指令.md#set-location)。

### Push-Location / Pop-Location
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：把目录记进栈再切换，用 Pop 退回，对应 bash 的 `pushd` / `popd`。
- 与 Windows PowerShell 的差异：`pushd` / `popd` 别名未实现，须用全名。
例：
- `Push-Location /etc; Pop-Location` —— 记下当前目录、切到 /etc、再退回（相当于 bash 的 `pushd /etc; popd`）。
- `Push-Location /usr; Push-Location /bin; Pop-Location; Get-Location` —— 连续压两个目录再弹一个，回到 /usr（相当于 bash 的 `pushd /usr; pushd /bin; popd; pwd`）。

原版官方说明：[Push-Location](指令详解-原版跨平台指令.md#push-location)、[Pop-Location](指令详解-原版跨平台指令.md#pop-location)。

## 看文件和目录

### Get-ChildItem（dir、ls、gci）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：列出目录内容，对应 bash 的 `ls`；`-Recurse` 相当于 `find`。
- 与 Windows PowerShell 的差异：`-Force` 无隐藏文件效果。
例：
- `dir` —— 列出当前目录（相当于 bash 的 `ls`）。
- `Get-ChildItem /etc -Filter "*.conf" -Recurse | Where-Object Length -gt 1000` —— 递归找 /etc 下大于 1KB 的 .conf 文件（大致相当于 bash 的 `find /etc -name '*.conf' -size +1000c`）。

原版官方说明：[Get-ChildItem](指令详解-原版跨平台指令.md#get-childitem)。

### Get-Item（gi）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：看单个文件或目录的信息，对应 bash 的 `stat`。
- 与 Windows PowerShell：行为一致。
例：
- `Get-Item /etc/hostname` —— 显示 hostname 的信息（相当于 bash 的 `stat /etc/hostname`）。
- `(Get-Item /etc/passwd).Length` —— 取 passwd 的字节数（相当于 bash 的 `stat -c %s /etc/passwd`）。

原版官方说明：[Get-Item](指令详解-原版跨平台指令.md#get-item)。

### Get-ItemProperty（gp）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：看路径的各项属性（名字、大小、修改时间、权限），对应 bash 里 `stat` 的完整输出。
- 与 Windows PowerShell 的差异：只输出 5 个字段。
例：
- `gp /etc/hostname` —— 显示 hostname 的 Name/FullName/Length/LastWriteTime/Mode。
- `Get-ItemProperty /etc | Format-List *` —— 把 /etc 的所有属性逐行列出。

原版官方说明：[Get-ItemProperty](指令详解-原版跨平台指令.md#get-itemproperty)。

### Set-ItemProperty（sp）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：改文件属性，目前支持改修改时间，对应 bash 的 `touch`。
- 与 Windows PowerShell 的差异：只支持改修改时间，其它属性忽略。
例：
- `Set-ItemProperty a.txt -Name LastWriteTime -Value $null` —— 把 a.txt 的修改时间设为当前时间（相当于 bash 的 `touch a.txt`）。
- `Set-ItemProperty a.txt -Name LastWriteTime -Value $null; (Get-Item a.txt).LastWriteTime` —— 改完再看时间确认。

原版官方说明：[Set-ItemProperty](指令详解-原版跨平台指令.md#set-itemproperty)。

### New-Item（ni）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：新建文件或目录，对应 bash 的 `touch` 和 `mkdir`。
- 与 Windows PowerShell：行为一致。
例：
- `New-Item -ItemType Directory newdir` —— 建目录 newdir（相当于 bash 的 `mkdir newdir`）。
- `New-Item -ItemType Directory -Force a/b/c; New-Item a/b/c/f.txt` —— 递归建目录再在里面建文件（相当于 bash 的 `mkdir -p a/b/c && touch a/b/c/f.txt`）。

原版官方说明：[New-Item](指令详解-原版跨平台指令.md#new-item)。

### Remove-Item（rm、del、erase、rd、rmdir、ri）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：删除文件或目录，对应 bash 的 `rm`。
- 与 Windows PowerShell 的差异：路径不存在时静默忽略（PowerShell 会报"找不到路径"错误）。
例：
- `rm old.txt` —— 删文件（相当于 bash 的 `rm old.txt`）。
- `Remove-Item -Recurse -Force build/` —— 连目录带内容强删（相当于 bash 的 `rm -rf build/`）。

原版官方说明：[Remove-Item](指令详解-原版跨平台指令.md#remove-item)。

### Copy-Item（cp、copy、cpi）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：复制，对应 bash 的 `cp`。
- 与 Windows PowerShell：行为一致。
例：
- `cp a.txt b.txt` —— 复制 a.txt 成 b.txt（相当于 bash 的 `cp a.txt b.txt`）。
- `Copy-Item -Path src/ -Destination dst/ -Recurse` —— 整个目录复制（相当于 bash 的 `cp -r src/ dst/`）。

原版官方说明：[Copy-Item](指令详解-原版跨平台指令.md#copy-item)。

### Move-Item（mv、move、mi）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：移动或改名，对应 bash 的 `mv`。
- 与 Windows PowerShell 的差异：目录移动需加 `-Recurse`。
例：
- `mv a.txt b.txt` —— 把 a.txt 改名成 b.txt（相当于 bash 的 `mv a.txt b.txt`）。
- `Move-Item -Path *.log -Destination logs/ -Recurse` —— 把一堆日志移进 logs/（相当于 bash 的 `mv *.log logs/`）。

原版官方说明：[Move-Item](指令详解-原版跨平台指令.md#move-item)。

### Rename-Item（ren、rni）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：改名，对应 bash 的 `mv`（同目录改名）。
- 与 Windows PowerShell：行为一致。
例：
- `ren old.txt new.txt` —— 把 old.txt 改成 new.txt（相当于 bash 的 `mv old.txt new.txt`）。
- `Get-ChildItem *.tmp | ForEach-Object { Rename-Item $_ -NewName ($_.Name -replace ".tmp",".txt") }` —— 把所有 .tmp 文件改成 .txt。

原版官方说明：[Rename-Item](指令详解-原版跨平台指令.md#rename-item)。

### Invoke-Item（ii）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：用系统默认程序打开文件，对应 `xdg-open`。
- 与 Windows PowerShell 的差异：目前只打印路径，不真正打开。
例：
- `ii README.md` —— 目前只是把 README.md 这个路径打印出来。
- `Invoke-Item -Path ./report.pdf` —— 打印 report.pdf 的路径。

原版官方说明：[Invoke-Item](指令详解-原版跨平台指令.md#invoke-item)。

### Get-PSDrive（gdr）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：列出驱动器（根目录名显示成 `C`，7 风格显示 `/`），语义上对应 bash 的 `df`。
- 与 Windows PowerShell 的差异：只有根驱动器和 Env 两个。
例：
- `gdr` —— 列出驱动器。
- `Get-PSDrive | Select-Object Name,Root,CurrentLocation` —— 只看名字、根、当前位置。

原版官方说明：[Get-PSDrive](指令详解-原版跨平台指令.md#get-psdrive)。

## 读写文件内容

### Get-Content（cat、type、gc）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：读文件内容，按行输出字符串对象，对应 bash 的 `cat`；`-Tail` 相当于 `tail`，`-TotalCount` 相当于 `head`。
- 与 Windows PowerShell：行为一致。
例：
- `cat /etc/hostname` —— 输出 hostname 的内容（相当于 bash 的 `cat /etc/hostname`）。
- `Get-Content -Path /var/log/syslog -Tail 20` —— 只读最后 20 行（相当于 bash 的 `tail -n 20 /var/log/syslog`）。

原版官方说明：[Get-Content](指令详解-原版跨平台指令.md#get-content)。

### Set-Content（sc）
- 类型：Go 实现。
- 版本：5.1 和 7（`sc` 别名只在 5 里）。发行版：所有。
- 功能：把内容写进文件（覆盖），对应 bash 的 `echo ... > 文件`。`-Encoding` 指定编码（utf8 / utf8BOM / utf8NoBOM / ascii / unicode / bigendianunicode / utf32 / bigendianutf32，默认 utf8 无 BOM）。
- 与 Windows PowerShell：行为一致。
例：
- `Set-Content out.txt "hello"` —— 把 hello 写进 out.txt（相当于 bash 的 `echo hello > out.txt`）。
- `Get-ChildItem -Name | Set-Content filelist.txt` —— 把文件名列表写进文件（相当于 bash 的 `ls > filelist.txt`）。
- `Set-Content utf8.txt "你好" -Encoding utf8BOM` —— 带 BOM 的 UTF-8（Windows 记事本可正常打开）。

原版官方说明：[Set-Content](指令详解-原版跨平台指令.md#set-content)。

### Add-Content
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：往文件末尾追加，对应 bash 的 `echo ... >> 文件`。
- 与 Windows PowerShell 的差异：`ac` 别名未实现，须用全名。
例：
- `Add-Content log.txt "新的一行"` —— 往 log.txt 末尾加一行（相当于 bash 的 `echo 新的一行 >> log.txt`）。
- `1..10 | Add-Content numbers.txt` —— 把 1 到 10 各一行追加进文件（相当于 bash 的 `seq 1 10 >> numbers.txt`）。

原版官方说明：[Add-Content](指令详解-原版跨平台指令.md#add-content)。

### Clear-Content
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：清空文件，对应 bash 的 `: > 文件`。
- 与 Windows PowerShell 的差异：路径不存在时静默创建一个空文件（PowerShell 会报"找不到路径"错误）。
例：
- `Clear-Content data.txt` —— 清空 data.txt（相当于 bash 的 `: > data.txt`）。
- `Get-ChildItem *.log | Clear-Content` —— 把当前目录所有 .log 文件清空。

原版官方说明：[Clear-Content](指令详解-原版跨平台指令.md#clear-content)。

### Set-Item（si）/ Clear-Item（cli）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：Set-Item 写文件或设环境变量，Clear-Item 清空文件。
- 与 Windows PowerShell 的差异：Set-Item 支持 `env:` 前缀设环境变量。
例：
- `Set-Item env:MY_VAR "value"` —— 设环境变量（相当于 bash 的 `export MY_VAR=value`）。
- `Set-Item -Path config.txt -Value "mode=fast"` —— 把内容写进 config.txt（相当于 bash 的 `echo mode=fast > config.txt`）。

原版官方说明：[Set-Item](指令详解-原版跨平台指令.md#set-item)。

### Get-FileHash
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有（程序自己算，不依赖外部命令）。
- 功能：算文件哈希，对应 bash 的 `sha256sum`、`md5sum`。
- 与 Windows PowerShell 的差异：支持的算法少几个。
例：
- `Get-FileHash /etc/hostname -Algorithm MD5` —— 算 MD5（相当于 bash 的 `md5sum /etc/hostname`）。
- `Get-ChildItem *.iso | Get-FileHash -Algorithm SHA256 | Select-Object Hash,Path` —— 批量算 SHA256（相当于 bash 的 `sha256sum *.iso`）。

原版官方说明：[Get-FileHash](指令详解-原版跨平台指令.md#get-filehash)。

### Select-String（sls）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：在文本里找匹配行，对应 bash 的 `grep`。
- 与 Windows PowerShell 的差异：无效正则不报错（只是不匹配）。
例：
- `Select-String -Path /etc/os-release "NAME"` —— 找 os-release 里带 NAME 的行（相当于 bash 的 `grep NAME /etc/os-release`）。
- `Get-Content server.log | Select-String -Pattern "ERROR|WARN" | Select-Object LineNumber,Line` —— 找 ERROR 或 WARN 行并显示行号（相当于 bash 的 `grep -nE 'ERROR|WARN' server.log`）。
- `Get-Content server.log | Select-String -Pattern "ERROR" -Quiet` —— 只问有没有 ERROR 行（相当于 bash 的 `grep -q ERROR server.log`）。

原版官方说明：[Select-String](指令详解-原版跨平台指令.md#select-string)。

## 路径处理

### Test-Path
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：判断路径是否存在，返回 True / False，对应 bash 的 `test -e`。`-PathType` 按类型过滤（Leaf 文件 / Container 目录）。
例：
- `Test-Path /etc/passwd` —— 判断文件在不在（相当于 bash 的 `test -e /etc/passwd`）。
- `Test-Path /etc/passwd -PathType Container` —— 判断它是不是目录（相当于 bash 的 `test -d /etc/passwd`）。
- `if (Test-Path config.json) { Get-Content config.json } else { "缺少配置文件" }` —— 在就读、不在就提示（相当于 bash 的 `[ -e config.json ] && cat config.json || echo 缺少配置文件`）。

原版官方说明：[Test-Path](指令详解-原版跨平台指令.md#test-path)。

### Resolve-Path / Convert-Path
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：把路径变成绝对路径，对应 bash 的 `realpath`。
- 与 Windows PowerShell 的差异：Resolve-Path 额外解符号链接。
例：
- `Resolve-Path .` —— 显示当前目录的绝对路径（相当于 bash 的 `realpath .`）。
- `Resolve-Path ./a/../b` —— 规整掉 .. 得到最终路径（相当于 bash 的 `realpath ./a/../b`）。

原版官方说明：[Resolve-Path](指令详解-原版跨平台指令.md#resolve-path)。

### Split-Path
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：拆路径，`-Leaf` 相当于 `basename`，`-Parent` 相当于 `dirname`。
- 与 Windows PowerShell：行为一致。
例：
- `Split-Path /etc/hostname -Leaf` —— 取最后一段 hostname（相当于 bash 的 `basename /etc/hostname`）。
- `Get-ChildItem -Name | ForEach-Object { Split-Path $_ -Parent }` —— 逐个取每个文件所在的目录。

原版官方说明：[Split-Path](指令详解-原版跨平台指令.md#split-path)。

### Join-Path
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：把两段路径拼起来。
- 与 Windows PowerShell：行为一致。
例：
- `Join-Path /tmp "test.txt"` —— 拼出 `/tmp/test.txt`。
- `Join-Path $HOME (Join-Path ".config" "app")` —— 拼出 `~/.config/app`。

原版官方说明：[Join-Path](指令详解-原版跨平台指令.md#join-path)。

## 进程和服务

### Get-Process（ps、gps）
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有（Linux 上读 /proc）。
- 功能：列出进程，对应 bash 的 `ps`。
- 与 Windows PowerShell 的差异：内存字段叫 Memory（PowerShell 叫 WS），值为物理内存字节数，与 PowerShell 的 WS 语义一致；`-Name` 按子串匹配（PowerShell 用精确名或通配符）。
例：
- `ps | Select-Object -First 5` —— 列前 5 个进程（大致相当于 bash 的 `ps -ef | head -5`）。
- `ps | Select-Object -Skip 1 -First 5` —— 跳过 1 个取前 5 个进程（大致相当于 bash 的 `ps -ef | tail -n +2 | head -5`）。
- `Get-Process | Where-Object ProcessName -like "*ssh*"` —— 挑出名字带 ssh 的进程（大致相当于 bash 的 `ps -ef | grep ssh`）。

原版官方说明：[Get-Process](指令详解-原版跨平台指令.md#get-process)。

### Stop-Process
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。

## 特殊用法

### sudo
`sudo` 不是内置的，它是外部命令透传：遇到不认识的命令，就直接在系统 PATH 里查找并执行系统命令。所以 `sudo apt install`、`sudo systemctl restart nginx` 这些跟在 bash 里写一模一样。另外，需要 root 的内置指令（服务、关机、时区、时间）会自动尝试用 sudo 来执行。
例：
- `sudo apt update` —— 就是 bash 的 `sudo apt update`。
- `sudo systemctl restart nginx && Get-Service nginx` —— 用 sudo 重启 nginx，成功后查看服务状态。

### 管道链 && 和 ||
这是 PowerShell 7 的写法：左边成功了（`$?` 为真）才执行 `&&` 右边；失败了才执行 `||` 右边。
例：
- `Test-Path /etc/passwd && echo "存在"` —— 存在才打印（相当于 bash 的 `[ -e /etc/passwd ] && echo 存在`）。
- `Get-Content 重要.txt 2>$null || echo "读取失败"` —— 读失败才打印（相当于 bash 的 `cat 重要.txt 2>/dev/null || echo 读取失败`）。

### 重定向
- `>` 把输出写进文件（覆盖），`>>` 追加，`2>` 把错误流写进文件，`2>$null` 把错误丢掉。
例：
- `Get-ChildItem -Name > list.txt` —— 把输出写进 list.txt（相当于 bash 的 `ls > list.txt`）。
- `Get-Content a.txt > out.txt 2> err.txt` —— stdout 进 out.txt、stderr 进 err.txt（相当于 bash 的 `cat a.txt > out.txt 2> err.txt`）。

### 比较运算符
`-eq`、`-lt`、`-like`、`-match` 等比较运算符在过滤脚本（如 `Where-Object { $_ -lt 100 }`）里通用。
- 比较时右操作数按左操作数类型转换（与 Windows PowerShell 一致）：左为数字则两边按数字比（`5 -lt "10"` 得 True），左为字符串则两边按字符串逐字符比、大小写不敏感（`"5" -lt "10"` 得 False）。

### 捕获变量 $Matches
`-match` / `-cmatch` 匹配成功后，捕获组会放进 `$Matches`；`$Matches[1]` 取第一个捕获组，命名组用 `$Matches.组名` 取。
例：
- `"abc123" -match "(\d+)"; $Matches[1]` —— 得 123。
- `"abc123" -match "(?<n>\d+)"; $Matches.n` —— 命名组用组名取，得 123。

### 7 运算符
这些是原版 PowerShell 7 的运算符，本程序 5 风格和 7 风格下都能用：
- `??` —— 左边是 $null 时取右边的值，否则取左边。例：`$name ?? "匿名"`（相当于 bash 的 `${name:-匿名}`）。
- `?:` —— 条件成立取前者，否则取后者。例：`$ok ? "通过" : "失败"`。
- `-f` —— 用 {N} 占位符把后面的值填进模板。例：`"共 {0} 个文件" -f (Get-ChildItem).Count`（思路对应 bash 的 printf）。
- `-in` / `-contains` —— 判断在不在集合里，范围也能用。例：`5 -in 1..10` 得 True，`1..10 -contains 5` 得 True。

### 哈希表成员
哈希表用 `.键名` 或 `["键名"]` 取值，键不区分大小写；有同名键时键优先于内置属性。`.Count` 是条目数，`.Keys` / `.Values` 分别给出键和值的数组。
例：
- `@{a=1;b=2}.Count` —— 得 2。
- `@{a=1;b=2}.Keys -join ","` —— 得 a,b。
