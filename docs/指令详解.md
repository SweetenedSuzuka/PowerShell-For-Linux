# PowerShell 指令详解

这份文档给每条指令写出**完整的、逐参数、逐字段**的说明。每条指令分两类：

- **Go 实现** —— 行为在本程序内部用 Go 复现，不调用外部命令。参数表写每个参数的含义与用法。
- **映射 Linux 命令** —— 直接调用系统里的原生命令（`systemctl`、`ping`、`xclip` 等）。参数表写每个参数映射到什么、哪些参数被忽略。

对应用户文档《指令参考.md》；用户文档里每条指令的"具体说明参见本文档对应一节"。

记号说明：

- 类型：`switch`（开关，写了就为真）、`string`（字符串）、`int`（整数）、`object`（任意对象）、`object[]`（对象数组）、`string[]`（字符串数组）、`path`（路径）、`scriptblock`（脚本块）。
- 位置参数：各参数表里 `（位置 N）` 标注的参数按 N 顺序接收位置实参；没标注的参数只接受命名形式，不占位置槽位。命名参数先占住自己的槽位，剩余位置实参依次落到没被占用的槽位；超过声明范围的实参保留为额外实参，个别指令无管道时把它们当数据（如 `Select-Object a,b`、`Get-Unique a b c`）。脚本块参数（如 `Where-Object { ... }` 的 FilterScript）先存后取，需要时才算，不用则不算。
- 常见参数（-ErrorAction / -ErrorVariable / -Verbose / -Debug / -WhatIf / -Confirm / -OutVariable / -OutBuffer / -WarningAction / -WarningVariable / -InformationAction / -InformationVariable / -PipelineVariable / -ProgressAction / -InputObject / -Encoding）：**所有指令都接受**，不报"找不到参数"。其中 -Verbose / -Debug / -WhatIf / -Confirm 这类开关型参数后跟的值仍按位置参数处理；-WhatIf / -Confirm 按各自语义生效；-ErrorAction 按取值控制错误处理（Continue 显示并记录、SilentlyContinue 只记录不显示、Ignore 不记录不显示、Stop 与 Inquire 转为可捕获的终止错误，无效取值报错）；其余取值型参数的值被忽略。下文参数表只列各指令特有参数，不再重复这些。
- 缺参处理：命令不带必要参数（如 -Path、-Name）时静默无输出，不报错（PowerShell 会报"缺少参数"错误）。
- `$?`：上一条命令是否成功。指令内部报错会把它置为 False（等价 bash 里命令退出码非 0）。
- 路径：相对路径基于当前目录解析；显示成 Windows 风格（根目录 `C:\`），操作的是真实 Linux 文件系统。
- 盘符：Linux 没有盘符概念，`C:` 只是系统盘的表示。输入 `C:\tmp`、`C:/tmp` 等同 `/tmp`，`C:` 或 `C:\` 就是根目录；其它盘符（`D:`、`E:` 等）一律报错，提示 Linux 上只用 C 盘表示系统盘。

## 一、进入与风格

### Set-PSVersion
- 类型：Go 实现（本程序扩展，官方没有）。
- 别名：switchstyle。
- 版本：本程序扩展。发行版：所有。
- 功能：切换 5.X / 7.X 命令格式。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Version`（位置 0） | string | 目标格式：`5`/`5.1` 开头 → 5 格式；`7` 开头 → 7 格式；其它值报错 |

- 位置参数等同 -Version。
- 副作用：改 `$PSVersionTable`（5 显示 PSVersion 5.1、PSEdition Desktop；7 显示 PSVersion 7、PSEdition Core、GitCommitId、OS、Platform）、横幅、别名表（5 增加 sc/curl/wget）、自动变量（$IsLinux/$IsWindows/$IsMacOS 只在 7 存在，5 下引用得 $null）。
- 输出：无。成功时打印一行"已切换到 X 风格"。

### Get-Host
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：返回主机对象。
- 参数：无。
- 输出：`System.Management.Automation.Internal.Host.InternalHost` 对象，字段：

| 字段 | 值 |
| :--- | :--- |
| `Name` | "ConsoleHost" |
| `InstanceId` | 本会话的随机 UUID（每次启动变化） |
| `UI` | 宿主界面对象，含 `SupportsVirtualTerminal`（恒 True）与 `RawUI` 类型名 |
| `CurrentCulture` | CultureInfo 对象（LCID/Name/DisplayName），按界面语言的登记表返回，界面语言未登记区域时用 zh-CN |
| `CurrentUICulture` | 同 CurrentCulture |

### Get-Location
- 类型：Go 实现。
- 别名：pwd、gl。
- 版本：5.1 和 7。发行版：所有。
- 功能：显示当前目录。
- 参数：无。
- 输出：`String`，即当前目录的 Windows 风格显示（根目录 `C:\`），对应 bash `pwd`。与 PowerShell 的差异：直接输出路径字符串，不包装成 PathInfo 表格。

### Set-Location
- 类型：Go 实现。
- 别名：cd、sl、chdir。
- 版本：5.1 和 7。发行版：所有。
- 功能：切换目录。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标目录。支持相对路径、`..`、`~`/`~/...`（家目录）。等价 bash `cd` |

- 行为：目录不存在或不是目录 → 报错写 stderr、$?=false。成功改当前目录。

### Push-Location
- 类型：Go 实现。
- 同组：Pop-Location。
- 版本：5.1 和 7。发行版：所有。
- 功能：把当前目录压栈并切换。
- 与 Windows 的差异：`pushd` 别名未实现，须用全名。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 要切到的目录；不写则只压栈不切换 |

- 行为：目录不存在 → 报错。对应 bash `pushd`。

### Pop-Location
- 类型：Go 实现。
- 同组：Push-Location。
- 版本：5.1 和 7。发行版：所有。
- 功能：弹栈回上一个目录。
- 与 Windows 的差异：`popd` 别名未实现，须用全名。
- 参数：无。
- 行为：栈空则无操作。对应 bash `popd`。

## 二、看文件和目录

### Get-ChildItem
- 类型：Go 实现。
- 别名：dir、ls、gci。
- 版本：5.1 和 7。发行版：所有。
- 功能：列出目录内容。对应 bash `ls` / `find`。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 起始路径，支持通配符（`*`、`?`、`[...]`）。默认 "." |
| `-Name` | switch | 只输出名字字符串，不输出完整对象（对应 `ls` 不带 `-l`） |
| `-Recurse` | switch | 递归子目录（对应 `find` / `ls -R`） |
| `-Directory` | switch | 只列目录 |
| `-File` | switch | 只列文件 |
| `-Filter` | string | 按通配符过滤文件名 |
| `-Force` | switch | 接受，不改变行为（无隐藏文件特殊处理） |

- 输出对象：`System.IO.FileInfo` / `System.IO.DirectoryInfo`，字段：

| 字段 | 含义 |
| :--- | :--- |
| `Name` | 文件名 |
| `FullName` | 绝对路径 |
| `Length` | 字节数（目录为 $null） |
| `LastWriteTime` | 修改时间（DateTime） |
| `PSIsContainer` | 是否目录 |
| `Mode` | 权限串（如 `drwxr-xr-x`，d 表示目录） |

- 表格默认列：Mode / LastWriteTime / Length / Name（对应 bash `ls -l` 的权限、时间、大小、名字各列）。
- 行为：路径不存在 → 静默跳过（对应 `ls` 对不存在路径的报错被忽略）。

### Get-Item
- 类型：Go 实现。
- 别名：gi。
- 版本：5.1 和 7。发行版：所有。
- 功能：看单个文件/目录信息。对应 bash `stat`。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径，支持通配符；可多个（`Get-Item a.txt,b.txt`） |

- 输出：单个 FileInfo/DirectoryInfo 对象，字段同 Get-ChildItem。
- 行为：路径不存在 → 报错、$?=false。

### Get-ItemProperty
- 类型：Go 实现。
- 别名：gp。
- 版本：5.1 和 7。发行版：所有。
- 功能：输出路径的属性对象。对应 bash `stat` 完整信息。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径 |
| `-Name`（位置 1） | string | 只保留该属性（不写则输出全部五个），如 `Get-ItemProperty x -Name Length` |

- 输出：`System.Management.Automation.PSCustomObject`，字段 Name / FullName / Length / LastWriteTime / Mode。

### Set-ItemProperty
- 类型：Go 实现。
- 别名：sp。
- 版本：5.1 和 7。发行版：所有。
- 功能：修改文件属性。目前仅支持修改时间。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径 |
| `-Name`（位置 1） | string | 属性名；为 `LastWriteTime` 时把修改时间设为当前时间（对应 bash `touch`） |
| `-Value`（位置 2） | object | 属性值；目前忽略，其它属性名也忽略（不报错） |

- 行为：文件不存在 → 报错。

### New-Item
- 类型：Go 实现。
- 别名：ni。
- 版本：5.1 和 7。发行版：所有。
- 功能：新建文件或目录。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 要新建的路径 |
| `-ItemType` | string | "Directory" 建目录（对应 `mkdir`）；其它值建文件（对应 `touch`） |
| `-Force` | switch | 目录用 `MkdirAll`（对应 `mkdir -p`）；文件已存在则不报错 |

- 输出：新建项对应的 FileInfo/DirectoryInfo 对象。
- 行为：文件已存在且无 -Force → 报错（与 PowerShell 语义一致，区别于 `touch` 的静默成功）。

### Remove-Item
- 类型：Go 实现。
- 别名：rm、del、rd、rmdir、ri、erase。
- 版本：5.1 和 7。发行版：所有。
- 功能：删除文件/目录。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径，可多个/通配 |
| `-Recurse` | switch | 目录整体删除，对应 `rm -r` |
| `-Force` | switch | 强制删除，对应 `rm -f`（文件也走 RemoveAll） |

- 行为：路径不存在 → 静默忽略。

### Copy-Item
- 类型：Go 实现。
- 别名：cp、copy、cpi。
- 版本：5.1 和 7。发行版：所有。
- 功能：复制。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 源路径，可多个 |
| `-Destination`（位置 1） | path | 目标路径 |
| `-Recurse` | switch | 目录整体复制，对应 `cp -r` |

- 行为：复制目录不加 -Recurse → 报错；目标为已存在目录时把源放进去（对应 `cp` 语义）；复制多个源时目标必须是已存在的目录，否则报错。

### Move-Item
- 类型：Go 实现。
- 别名：mv、move、mi。
- 版本：5.1 和 7。发行版：所有。
- 功能：移动/改名。实现为复制后删除源。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 源路径 |
| `-Destination`（位置 1） | path | 目标路径 |
| `-Recurse` | switch | 目录整体移动（同 Copy-Item，目录需加） |
| `-Force` | switch | 接受，目前无额外效果 |

- 行为：同 Copy-Item（目录需加 -Recurse），且复制成功后被删源。

### Rename-Item
- 类型：Go 实现。
- 别名：ren、rni。
- 版本：5.1 和 7。发行版：所有。
- 功能：给文件改名。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 旧路径 |
| `-NewName`（位置 1） | string | 新名字，只取叶子名，支持传完整路径 |

- 实现：`os.Rename(旧路径, 同目录/新名)`，对应 bash `mv 旧 同目录新名`。

### Invoke-Item
- 类型：Go 实现（占位）。
- 别名：ii。
- 版本：5.1 和 7。发行版：所有。
- 功能：用默认程序打开文件（对应 `xdg-open`）。**目前只打印路径，不真正调用 xdg-open，属占位。**

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 要打开的文件，当前仅打印其路径 |

### Get-PSDrive
- 类型：Go 实现。
- 别名：gdr。
- 版本：5.1 和 7。发行版：所有。
- 功能：列驱动器。语义上对应 bash `df`。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Name`（位置 0） | string | 只列出指定名的驱动器（如 `C`、`/`、`Env`） |

- 输出：PSDriveInfo 对象，字段：

| 字段 | 值 |
| :--- | :--- |
| `Name` | 根目录显示 "C"（不带冒号，7 显示 "/"）；另有 "Env" |
| `Root` | "/" |
| `CurrentLocation` | 当前目录的 Windows 风格显示 |

- 表格列 Name/Root/CurrentLocation。

## 三、读写文件内容

### Get-Content
- 类型：Go 实现。
- 别名：cat、type、gc。
- 版本：5.1 和 7。发行版：所有。
- 功能：读文本文件。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 文件路径；可多个（`Get-Content a.txt,b.txt` 逐个读取，-TotalCount/-Tail 对每个文件分别生效） |
| `-Raw` | switch | 整块读出不按行切（对应 `cat`） |
| `-TotalCount` | int | 只读开头 N 行（对应 `head -n N`） |
| `-Tail` | int | 只读末尾 N 行（对应 `tail -n N`） |

- 输出：每行一个 `String` 对象（不含行尾换行）。空文件无输出。
- 行为：路径不存在 → 报错、$?=false，等价 `cat` 对不存在文件的报错。

### Set-Content
- 类型：Go 实现。
- 别名：sc（只在 5 风格）。
- 版本：5.1 和 7。发行版：所有。
- 功能：覆盖写文件。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标文件 |
| `-Value`（位置 1） | object | 要写入的内容；管道输入优先于它 |
| `-Encoding` | string | 编码：utf8（默认无 BOM）/ utf8BOM / utf8NoBOM / ascii / unicode（UTF-16LE）/ bigendianunicode / utf32 / bigendianutf32；未知名按 UTF-8 |

- 实现：把每个对象字符串逐行写进文件（覆盖），对应 `echo ... > 文件` / `tee`。行尾自动加换行。

### Add-Content
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：追加写文件。
- 与 Windows 的差异：`ac` 别名未实现，须用全名。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标文件 |
| `-Value`（位置 1） | object | 要追加的内容；管道输入优先 |

- 实现：追加模式（O_APPEND），对应 `echo ... >> 文件`。

### Clear-Content
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：清空文件。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标文件 |

- 实现：`os.WriteFile(路径, 空, 0644)`，对应 `: > 文件` / `truncate -s 0`。

### Set-Item
- 类型：Go 实现。
- 别名：si。
- 同组：Clear-Item。
- 版本：5.1 和 7。发行版：所有。
- 功能：Set-Item 写文件或设环境变量；Clear-Item 清空文件。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径；若以 `env:` 开头则视为环境变量名 |
| `-Value`（位置 1） | object | 要写入的内容 |

- 行为：`env:NAME` → `os.Setenv(NAME, 值)`，对应 `export NAME=值`。普通路径 → 写文件。

### Clear-Item
- 类型：Go 实现。
- 别名：cli。
- 版本：5.1 和 7。发行版：所有。
- 功能：清空文件。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径；目录则无操作 |

### Get-FileHash
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有（程序自己算，不依赖外部命令）。
- 功能：算文件哈希。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 文件路径，支持通配符 |
| `-Algorithm` | string | 算法：SHA256（默认）/ SHA1 / MD5 / SHA512（也认 SHA2_256/SHA2_512） |

- 实现：纯 Go（crypto 标准库）。对应 `sha256sum` / `md5sum` / `sha1sum` / `sha512sum`。
- 输出：FileHash 对象，字段 Algorithm（大写）、Hash（小写十六进制）、Path。

### Select-String
- 类型：Go 实现。
- 别名：sls。
- 版本：5.1 和 7。发行版：所有。
- 功能：按正则找匹配行。对应 bash `grep -E`。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Pattern`（位置 0） | string | 正则模式 |
| `-Path`（位置 1） | path | 要搜的文件 |
| `-SimpleMatch` | switch | 按字面匹配，对应 `grep -F` |
| `-CaseSensitive` | switch | 大小写敏感匹配；缺省则不敏感（对应 `grep -i`） |
| `-Quiet` | switch | 只报告是否命中：命中输出单个 True，未命中无输出（对应 `grep -q`） |

- 无 -Path 时从管道输入搜。
- 输出：MatchInfo 对象，字段 LineNumber（从 1 起）、Line、Path、Pattern。
- 行为：默认大小写不敏感；无效正则 → 不匹配（不报错）。
- LineNumber：文件输入逐行扫描，空行也计入行号；管道输入每个对象整体作为一行参与匹配，LineNumber 是对象在流中的序号，未匹配的对象同样占号。

## 四、路径处理

### Test-Path
- 类型：Go 实现。
- 版本：5.1 和 7。发行版：所有。
- 功能：判断路径存在。返回 Bool，对应 bash `test -e`。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径，支持通配符；可多个（`Test-Path a.txt,b.txt`） |
| `-PathType` | string | 类型过滤：`Leaf` 只认文件、`Container` 只认目录、`Any`/缺省不限制 |

- 行为：路径存在（含通配命中任意一个）→ True，否则 False。`-PathType` 在存在性之上再按类型过滤。不存在不算错误（$? 保持 true）。

### Resolve-Path
- 类型：Go 实现。
- 同组：Convert-Path。
- 版本：5.1 和 7。发行版：所有。
- 功能：转绝对路径。对应 bash `realpath`。

| 参数 | 类型 | 含义 |
| :--- | :--- | :--- |
| `-Path`（位置 0） | path | 目标路径 |

- 实现：Resolve-Path 额外 `EvalSymlinks`（解符号链接）；Convert-Path 只 Clean。

### Convert-Path
- 类型：Go 实现。
- 同组：Resolve-Path。
- 版本：5.1 和 7。发行版：所有。
- 功能：转绝对路径（不解符号链接）。

## 特殊机制

### 外部命令透传
- 未命中内置/别名/函数的命令，在 PATH 中查找并执行（`os/exec`），stdin/stdout/stderr 透传。
- 退出码写入 `$LASTEXITCODE`；退出码非 0 → $?=false。
- 管道末尾的外部命令直连终端；管道中间的外部命令 stdout 按行转 String 对象进入管道，stdin 接收左侧对象文本。
- 找不到 → stderr 报"无法将 X 识别为 cmdlet、函数、脚本文件或可运行程序的名称"，$?=false。

### sudo
- `sudo` 是外部命令，直接透传到系统 sudo。需要 root 的内置指令（服务/关机/时区/时间）内部自动调用 `sudo`（先试无 sudo，失败再试 `sudo`）。

### 管道链 && / ||
- PowerShell 7 语法：左命令 $? 为真才执行 `&&` 右侧；$? 为假才执行 `||` 右侧。
- 对应 bash 的 `&&` / `||`。

### 重定向
- `> 文件`：覆盖写（等价 `Out-File`）；`>> 文件`：追加（`Out-File -Append`）。
- `2> 文件`：把错误流写文件；`2>$null`：丢弃错误（io.Discard）。
- `> $null`：丢弃输出。
- 外部命令的重定向：文件作为该命令的 stdout/stderr。

### 裸运算符参数
- 命令位置参数以单独 `/`、`-`、`+`、`*`、`%` 出现且后跟语句结束（如 `Write-Output /`、`cd -`）时，当作字符串参数而不是运算符。
- 命名参数后跟这些符号同样当作值（如 `Get-PSDrive -Name /`、`Set-Location -Path /`）。

### 比较运算符
- `-eq`/`-ne`/`-lt`/`-gt`/`-le`/`-ge` 等比较时：右操作数按左操作数类型转换——左为数字则两边按数字比（如 `5 -lt "10"` 得 True）；左为字符串则两边按字符串逐字符比、大小写不敏感（如 `"5" -lt "10"` 得 False）；`$null` 只与 `$null` 相等。
- `-like`/`-match` 默认大小写不敏感，`-c*` 前缀为敏感变体。
- 范围运算符 `..` 绑定比比较运算更紧：`1..3 -gt 1` 先成范围 `1 2 3` 再过滤，得 `2 3`；`5 -in 1..10`、`1..10 -contains 5` 均可用。

### 捕获变量 $Matches
- 标量 `-match` / `-cmatch` 匹配成功后，把捕获组写进自动变量 `$Matches`（哈希表）。
- 键规则与真 PowerShell 一致：`0` 是整体匹配；命名组 `(?<name>...)` 用组名作键；未命名组 `(...)` 按其在未命名组中的序号（从 1 起）作键；未参与匹配的组不写入。
- 不匹配、数组左值、`-notmatch` 都不改动 `$Matches`（保留上一次的值）；未匹配过时 `$Matches` 为 `$null`。
- 差异：命名组只支持 `(?<name>...)`（内部转成 Go 的 `(?P<name>...)`）；`(?'name'...)` 与环视 `(?<=...)` 等 Go 正则不支持。

### 错误变量 $Error
- 会话里每报一次错（非终止错误、throw、参数绑定失败）都累积一条记录进自动变量 `$Error`，最新在 `$Error[0]`；被 try/catch 捕获的错误同样进入。
- 数组方法可用：`.Count` 取条数；`.Clear()` 清空；`.RemoveAt(n)` 删除指定下标。容量上限 256 条，超出时丢弃最旧的。
- `$Error[0].Message` 取最近一条错误的消息文本。
- bash 无对应机制，思路接近把每次命令的 stderr 收进一个可检查的列表。

### 首选项变量 $ErrorActionPreference
- 未赋值时读到默认值 `Continue`；赋值只接受 `Continue`、`SilentlyContinue`、`Stop`、`Inquire`、`Ignore`，无效值报错且不生效。
- 没有显式 `-ErrorAction` 的指令按它的取值处理错误；显式 `-ErrorAction` 覆盖它。函数内赋值只在局部生效。
- 表达式求值、参数绑定、脚本加载这类错误没有 `-ErrorAction`，只看首选项。

### 格式运算符 -f
- `"模板 {0} {1}" -f 值1, 值2`：按 .NET 风格格式串把后面的值填进占位符，思路对应 bash 的 `printf`。
- 支持 `{N}`、`{N,宽度}`（空格对齐，负宽度左对齐）、`{N:规格}`；规格支持 `D`/`Dk`（十进制，k 位补零）、`X`/`x`（十六进制）、`Fk`（k 位小数）、`Nk`（千分位 + k 位小数），未知规格退化为原样字符串。
- `{{` 与 `}}` 转义字面大括号；参数可为范围/数组（自动展平）。占位符下标越界 → 报错并置 `$?=false`（与 PowerShell 抛错一致）。

### 空合并 ?? 与三元 ?:
- `$a ?? $b`（7）：`$a` 为 `$null` 时取 `$b`，否则取 `$a`；短路，右侧只在左侧为空时才求值。对应 bash 的 `${a:-$b}`。
- `$cond ? $真 : $假`（7）：条件为真取真分支，否则取假分支；右结合（`$a ? $b : $c ? $d : $e` 等价 `$a ? $b : ($c ? $d : $e)`）。
- 二者都是真 PowerShell 7 的语法；本程序不设风格门控，5.X 风格下同样可用。

### 类型字面量与强制转换
- `[int]"42"` 把值转换成整数；小数或非数字字符串会报错（bash 里数值取整常写 `$((10#$x))`，语义相近）。
- 支持的类型：`int`、`double`、`string`、`bool`、`datetime`、`hashtable`、`array`、`void`；数组元素逐个转换写 `int[]`。
- `[datetime]"2020-01-02"` 得到日期对象，之后可取 `.Year` 等字段。
- `[void](命令或表达式)` 执行并丢弃输出，相当于 bash 的 `> /dev/null`。
- 类型名可以单独保存：`$t = [int]`，之后 `5 -is $t` 判断类型；`"7" -as [double]` 转换失败时得到空值而不是报错。
- `[类型]::成员` 调用静态方法与属性（bash 无对应语法）：`[math]::Sqrt(4)` 得 2、`[math]::Floor(1.9)` 得 1、`[math]::Round(2.5)` 得 2（四舍六入五取偶）、`[math]::Pow(2, 10)` 得 1024；`[string]::Join(",", 1, 2)` 得 `1,2`、`[string]::Format("{0}-{1}", "a", "b")` 得 `a-b`；`[datetime]::Now.Year` 取当前年份；`[guid]::NewGuid()` 生成随机 GUID。
- 形参可标注类型：`function f([int]$x)` 或脚本开头 `param([int]$n)`；位置实参、命名实参与默认值都按类型字面量的同一规则转换，`[int[]]` 标注把单值包成单元素数组；实参无法转换时报错，函数体或脚本主体不再执行（bash 无对应语法）。

### 脚本块与调用运算符 &
- `{ ... }` 是脚本块：语句序列先存后执行。作为值保存（`$sb = { ... }`）或传给脚本块参数（如 `Where-Object { ... }`）；显示为 `{ ... }`。
- `& 调用目标 实参...` 执行调用目标：目标是脚本块时按函数语义执行——块体开头的 `param()` 声明形参，位置/命名实参与默认值绑定同 function，剩余实参进 `$args`，管道输入经 `$input` 进入；目标是命令名字符串时按名字调用该命令（bash 无直接对应，思路接近 `eval "cmd args"`）。`&` 后缺调用目标报错。
- `$sb = { param($x) $x * 2 }; & $sb 21` 得 42；`& { "a"; return "v"; "b" }` 得 `a`、`v`。
- `$block.Invoke(实参...)` 同样执行脚本块并把输出收集成数组：`{ 1; 2 }.Invoke()` 得含 1 与 2 的数组。
- 脚本块内可见外层变量（与 PowerShell 一致的动态作用域）；块内 throw 可被调用方的 try/catch 捕获。

### 函数的 begin/process/end 与 filter
- 函数体开头可写命名块：`function f { begin { ... } process { ... } end { ... } }`。begin 先跑一次，process 对管道每项执行（`$_` 绑定当前项），end 最后跑一次；三块顺序不限，但必须连续出现在体开头，裸语句与命名块混写、重复块名报错。
- 直调（无管道）时 process 以 `$null` 跑一次；管道输入为零项时 begin/end 照跑、process 不执行。
- `param()` 声明与命名块共存，形参在三个块内都可用。
- process 内 `return` 只结束当前项的处理，继续下一项；begin/end 内 `return` 结束整个函数。
- `filter f { ... }` 是单块函数：Body 即 process，逐项绑定 `$_`，也可带 begin/process/end 命名块。
- 命名块内 `break`/`continue` 没有所属循环，沿调用栈向上传播终止当前执行段（与 PowerShell 一致）。

### 成员访问与哈希表属性
- `$x.属性` 取成员，支持链式 `$x.a.b` 与方法调用 `$x.M(...)`（最后一段紧跟括号即方法）。
- 哈希表按"键优先于属性"取成员：先找同名键，找不到才落到内置属性。键不区分大小写。
- 哈希表内置属性：`.Count` 返回条目数；`.Keys` / `.Values` 返回按插入顺序排列的键/值数组；`.Length` 未定义为哈希表属性，按有值标量返回 1。
- 与真 PowerShell 的差异：真 `@{...}` 键序不保证，本程序按插入顺序（等同 `[ordered]@{}`）；真 `$h.Keys[0]` 因 KeyCollection 不支持整数下标而返回整个集合，本程序返回首个键。
